Requires (one-time)

Incremental selection built into Neovim 0.12
In Visual mode an grows the selection to the parent node, in shrinks it to a child, and ]n / [n move it to the next / previous node (:h treesitter-incremental-selection). The master branch's <C-Space> / <BS> maps are gone on main.

UI Suite

Statusline (lualine)
Global statusline (laststatus=3). Sections: mode · git branch + diff · diagnostics · filetype · filename · macro indicator · encoding · pos.
Bufferline
Tabs per buffer. Slant separators. Diagnostic counts visible per tab. Auto-hides when only one buffer is open. Shifts when neo-tree opens. Loads at startup, so pinned buffers come back pinned when auto-session restores a session.
Superscript ordinals (¹ ² ³ …) match visual positions until pinning reorders buffers. <leader>1…<leader>9 jump by visual position; the displayed ordinal can then differ. Beyond 9 it is omitted to avoid clutter; use <leader>bj (letter picker) or <leader>fb for the rest.
Mouse — left = focus tab · middle = no-op · right = context menu (open in split/vsplit, copy path / filename, toggle pin, close, close others). Bufferline's default right-click is bdelete; we override it. The menu is a small custom floating window rather than vim.ui.select — that route hit a progressive-indent glitch in our setup (telescope-ui-select dropdown theme + custom mappings; not a generic telescope bug). Press 1..8 to jump straight to an action, or j/k + <CR>. q or <Esc> closes.
Scrolling — bufferline auto-scrolls to keep the active tab visible; press <S-l> / <S-h> to cycle through, or <leader>bj to letter-pick. There's no mouse-wheel scroll on the tab bar itself.
Per-tab buffers (scope.nvim) — each tab shows only the buffers you opened in it (VS-Code-style "each tab owns its files"); Vim buffers are global, so scope.nvim toggles buflisted on tab switch and bufferline just follows. <leader>fb lists this tab's buffers, <leader>fB lists all tabs', :ScopeMoveBuf <tab> moves one. Survives sessions via sessionoptions+=globals and auto-session's :ScopeSaveState/:ScopeLoadState hooks.
Incline
Floating filename in top-right of each split. Shows ● when modified.
Cursor effects
neoscroll smooths C-d / C-u, C-f / C-b, C-y / C-e and zt / zz / zb · smear-cursor animates the cursor between positions.

Swap files collisions & crash recovery

'swapfile' is on. Opening a file that already has a swap is handled by a guard (default on) so it is livable rather than noisy — behaviour depends on who owns the swap.
File open in another Nvim Live owner detected → the file opens read-only here with a one-line notice. Close it there, then :e! to take over.
Crash leftover No live owner → a concise recovery prompt (Recover / Open RO / Edit / Delete / Quit), replacing Vim's ~17-line E325 block. The default button follows the swap: Delete when it holds no unsaved changes; Open read-only, with a warning, when the file on disk is newer than the swap (compare before you recover); otherwise Recover. Esc quits.
Another / unknown host The file opens read-only because a local PID check cannot establish the remote owner's liveness. Verify that editor is closed before taking over. A different Unix user's swap retains Neovim's stock prompt.
Unreadable swap Empty or damaged → the guard avoids the stock E325 prompt during session restore. An empty swap older than a minute is deleted; any other is kept and the file opens read-only with a notice naming the swap. :SwapDelete, then :e!, to edit.
:SwapGuardToggle Flip the guard. Off restores edit-anyway + W325 for a live local same-user owner; otherwise Neovim's stock prompt. Affects the next collision.
:SwapDelete Delete the current buffer's leftover swap without hunting the path — it scans the swap dir and matches by the swap's recorded file name (needed because swapname() is empty after Edit-anyway / Open-RO), plus an unreadable swap the guard opened the file over. Shows the exact path + facts and asks to confirm (default Cancel). This session's own active swap is left alone.
:SwapDelete {path} Delete a specific swap file by path — clears a leftover without opening the file it belongs to. Refuses any swap a different running Nvim is actively using, and anything that isn't a swap (a link, a folder, a file not named *.sw?). An unreadable or foreign-host swap needs :SwapDelete! {path}, after checking that it holds no needed work and its remote editor is closed.
:SwapClean Review swaps in scannable 'directory' entries: lists the leftovers it would delete (no running local owner and no unsaved changes, or unreadable, zero-byte swaps older than a minute) and the ones it keeps (running process, unknown/remote owner, unsaved changes or unreadable data). Per-file . entries cannot be scanned globally. One confirm, default Cancel. Full workflow, shell commands per OS: docs/workflows/swap-files.md.
